# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately through
[GitHub's private vulnerability reporting](https://github.com/kpab/mattermost-plugin-recurring/security/advisories/new)
on this repository. That opens a draft advisory visible only to you and the
maintainer.

Please include what the issue is, how to reproduce it, and which version of the
plugin and of Mattermost you saw it on.

## What to expect

- An acknowledgement within a few days.
- A fix for anything of medium severity or above within 14 days of that
  acknowledgement, in line with the
  [Mattermost Marketplace requirements](https://developers.mattermost.com/integrate/marketplace-submissions/).
- Credit in the release notes, unless you would rather not be named.

## Scope

This policy covers the plugin in this repository. Vulnerabilities in Mattermost
itself belong to
[Mattermost's responsible disclosure process](https://mattermost.com/security-vulnerability-report/)
(`responsibledisclosure@mattermost.com`).
